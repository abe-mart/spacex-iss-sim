OPTIONAL / EXPERIENCED PILOTS

Challenge Mode

After a successful docking, you can test your controller against a harder mission. Challenge Mode is available in the Autopilot and AI Agent tracks; choose a mission in the local flight panel before launching.

How to start a mission

If you have not docked yet, start with the standard Autopilot or AI Agent track. Challenge missions are optional, use the same interface, and have their own standings.

  1. Download the latest starter from your track's setup page.
  2. Start the simulator server with python -m hackathon.server (add --track agent for the AI Agent track).
  3. Open Optional · Challenge Mode in the local flight panel, choose a mission, and launch. Then start your autopilot or agent.
01 / FILTER & ESTIMATE

Noisy instruments

Position measurements vary by up to 0.5 m per axis and velocity by 0.03 m/s. Filter the telemetry to estimate the true state. Attitude measurements are not affected.

The capsule's motion and the docking rules are unchanged.

02 / ADAPT YOUR CONTROLLER

Broken thruster

The translate_left thruster produces no force. Dock using the remaining thrusters and the capsule's attitude. Every crew faces the same failed thruster.

03 / IDENTIFY THE SYSTEM

Scrambled controls

The six translation commands drive different translation thrusters. Identify the mapping with small test pulses, then dock. Rotation commands work normally. The mapping is the same for every attempt during the event.

View mission standings ↗

Scoring

Every ranked attempt in a mission uses the same starting position, thruster fault, and noise sequence. Each mission has separate Autopilot and AI Agent standings, and challenge results do not appear on the main leaderboard. The lowest simulation time wins, and fewer thruster pulses break ties.

Results are reported by the browser and reviewed by event staff.
