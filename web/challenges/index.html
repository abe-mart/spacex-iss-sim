01 / FILTER & ESTIMATE

Noisy instruments

Position measurements vary by up to 0.5 m per axis and velocity by 0.03 m/s. Filter telemetry and estimate the true state. Attitude instruments remain reliable.

The ship's motion and docking rules stay unchanged. Noise follows simulation steps, so rereading while paused returns the same measurements.

Broken thruster

The translate_left thruster produces no force. Work around it with ship attitude and remaining thrusters. The failed thruster is disclosed so every crew faces the same problem.

03 / IDENTIFY THE SYSTEM

Scrambled controls

The six translation commands drive different translation thrusters. Discover their mapping with small test pulses, then dock. Rotation commands still work normally. The mapping stays the same for every attempt within this event.

Fair competition

Every ranked attempt in a mission uses the same event start, fault configuration, and noise seed. Each scenario has separate Autopilot and AI Agent standings; challenge scores never enter the main leaderboard. Lowest simulation time wins, then pulse count.

Archive/reset starts a fresh event and mission seeds. These remain browser-reported hackathon scores with staff review.
