ADVANCED / FLIGHT SETUP

AI Agent

Build an AI agent that flies the capsule. The simulator runs in real time and does not wait for the agent, so the agent must make decisions quickly and account for the time it spends thinking.

⬇ Download the starter kit (.zip)

  1. Download the starter kit with the button above, unzip it, and open a terminal in the dock-the-capsule folder.
  2. Start the simulator server: python -m hackathon.server --track agent (use py on Windows or python3 on macOS if needed). The server opens the simulator in your browser and prints the autopilot URL your agent connects to.
  3. In the browser, log in, enter a crew name, and press LAUNCH FLIGHT.
  4. Start your agent. The agent must run on this computer, because the simulator server only accepts local connections.

Example agent

The starter kit includes agent_pilot.py, an example in which Claude flies the capsule through tool calls. It uses your own Anthropic API key:

pip install anthropic
export ANTHROPIC_API_KEY=sk-ant-...      # Windows PowerShell: $env:ANTHROPIC_API_KEY="sk-ant-..."
python agent_pilot.py

The example makes one Claude call per decision. You can improve it by changing the prompt and tools, by dividing the work between Claude and your own code, or by replacing it with a different agent.

Agent briefing

To use a coding agent such as Claude Code instead, give it this briefing. The Copy agent briefing button in the local flight panel fills in your actual autopilot URL.

Testing faster than real time

To test more quickly, open Simulation speed in the flight panel and choose 2×, 4×, or 8× before launching. Flights faster than real time are not submitted to the leaderboard.

Docking and scoring

Position is relative to the docking port: x is the distance along the docking axis, y is the sideways offset, and z is the vertical offset. Units are meters, meters per second, and degrees. The capsule docks when the range is below 0.2 m, roll, pitch, and yaw are each within 0.2°, and each velocity component is at or below 0.24 m/s. Contact with the station anywhere else, or drifting more than 500 m away, ends the flight.

Only successful real-time flights appear on the leaderboard. The lowest simulation time wins, and fewer thruster pulses break ties. Keep the simulator tab visible during a flight, because browsers slow down hidden tabs.

Results are reported by the browser and reviewed by event staff.

Challenge Mode

After a successful docking, you can try a harder mission: noisy instruments, a broken thruster, or scrambled controls. Choose a mission in the local flight panel before launching. Challenge results have separate standings.
