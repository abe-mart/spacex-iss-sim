ADVANCED / FLIGHT SETUP

AI Agent

Bring your own agent with terminal or Python tools on this laptop. The agent reads telemetry and decides what to do during the flight.

  1. Download the starter kit, unzip it, and open a terminal in the dock-the-capsule folder.
  2. Run python agent_bridge.py --event https://YOUR-SITE.netlify.app. Use py on Windows or python3 on macOS.
  3. The helper opens the local simulator. Choose your crew name, enter the event code, and click LAUNCH FLIGHT.
  4. Click Copy agent briefing in that local flight panel and paste it into your agent. The briefing already contains the actual API address and temporary controller token.
  5. Keep the terminal and simulator tab open and visible while your agent flies. Successful results upload automatically.

The helper also writes AGENT_CONNECTION.md beside the Python files. Give that file to your agent if you prefer.

Preview the interface briefing

This template uses placeholders. The local simulator’s Copy button fills them in for you.

Cloud-only agents and notebooks cannot reach this laptop’s localhost. Use an agent with local tools. Your agent manages its own model/provider access; this track has no website API-key field.

Docking and scoring

Position: x is distance in front of the docking port, y is sideways, z is vertical. Units are meters, meters/second, and degrees. Dock at range below 0.2 m, roll/pitch/yaw within 0.2°, and each speed component at or below 0.24 m/s. Gravity stays enabled for scored flights. Fine controls are recommended for the final approach.

Only successful flights appear on each track's leaderboard. Lowest simulation time wins, then fewer pulses. Agent thinking and network delays don't count as simulation time. Keep the simulator tab visible—browsers throttle hidden pages.

Results are browser-reported with consistency checks and staff review. The event is a hackathon challenge, not a tamper-proof competition platform.
