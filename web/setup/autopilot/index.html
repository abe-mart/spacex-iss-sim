Build Your Autopilot

  1. Download the Python starter bundle and unzip it.
  2. Use Python 3.11 or newer, on the same computer as your browser.
  3. Open a terminal in the unzipped dock-the-capsule folder. Run python autopilot.py --event https://YOUR-SITE.netlify.app (Windows: py; macOS: python3).
  4. The helper opens the local simulator automatically. Join the event and click Launch in the flight panel.
  5. The reference controller flies in real time: the capsule keeps moving between control updates. Modify its Python code with your AI coding assistant and improve it.

Use state(), reset(), named thrusters, and batched commands() to control the real-time capsule. Pause/step is reserved for the AI Agent track. The helper serves both the page and API locally; no second server command or browser permission bypass is needed.

from dragon import Dragon

sim = Dragon.start_event("https://YOUR-SITE.netlify.app", track="autopilot")
state = sim.reset()  # waits until you launch in the browser
state = sim.commands({"command": "yaw_left", "count": 2})
# The capsule keeps moving while your controller reads and reacts.
state = sim.state()

Docking and scoring

Position: x is distance in front of the docking port, y is sideways, z is vertical. Units are meters, meters/second, and degrees. Dock at range below 0.2 m, roll/pitch/yaw within 0.2°, and each speed component at or below 0.24 m/s. Gravity stays enabled for scored flights. Fine controls are recommended for the final approach.

Only successful flights appear on each track's leaderboard. Lowest simulation time wins, then fewer pulses. Keep the simulator tab visible—browsers throttle hidden pages.

Results are browser-reported with consistency checks and staff review. The event is a hackathon challenge, not a tamper-proof competition platform.
