Build Your Autopilot

Write a control loop that reads the capsule's telemetry, estimates its state, computes control inputs, and fires the thrusters. The simulator runs in real time in your browser, and your autopilot connects to it through a small server on your computer. You can write the autopilot in Python, C, or C++.

  1. Download the starter kit and unzip it. You need Python 3.9 or newer on the same computer as your browser.
  2. Open a terminal in the dock-the-capsule folder and start the simulator server: python -m hackathon.server (use py on Windows or python3 on macOS if needed). The server opens the simulator in your browser and prints your autopilot URL.
  3. In the browser, log in, enter a crew name, and press LAUNCH FLIGHT.
  4. In a second terminal, run the example autopilot: python autopilot.py. It levels the capsule's attitude but does not dock. Making it dock is your task.

Leave the server running while you work. You can stop, edit, and restart your autopilot as often as you like, and launch a new flight from the browser whenever you are ready.

import hackathon.client as hackathon_client

connection = hackathon_client.connect()       # uses the URL saved by the server
data = hackathon_client.request_telemetry(connection)
state = data["state"]   # [x, y, z, x_dot, y_dot, z_dot, roll, pitch, yaw, roll_dot, pitch_dot, yaw_dot]
hackathon_client.send_control_inputs(connection, [0, 0, 0, 0, 1, 0])   # thruster pulses per axis

C and C++ autopilots use the header-only clients in include/. Build instructions are at the top of examples/autopilot.c and examples/autopilot.cpp; pass them the autopilot URL printed by the server.

Testing faster than real time

To test your controller more quickly, open Simulation speed in the flight panel and choose 2×, 4×, or 8× before launching. Flights faster than real time are not submitted to the leaderboard. Use the telemetry timestamp, not the wall clock, for controller timing.

Docking and scoring

Position is relative to the docking port: x is the distance along the docking axis, y is the sideways offset, and z is the vertical offset. Units are meters, meters per second, and degrees. The capsule docks when the range is below 0.2 m, roll, pitch, and yaw are each within 0.2°, and each velocity component is at or below 0.24 m/s. Contact with the station anywhere else, or drifting more than 500 m away, ends the flight.

Only successful real-time flights appear on the leaderboard. The lowest simulation time wins, and fewer thruster pulses break ties. Keep the simulator tab visible during a flight, because browsers slow down hidden tabs.

Results are reported by the browser and reviewed by event staff.
