BEGINNER / FLIGHT SETUP

Manual Piloting

Open the hosted simulator, choose a callsign, enter the event code if required, and launch. Nothing to install. Translation: W / S up/down, A / D left/right, E / Q forward/backward. Arrow keys control pitch/yaw; comma/period control roll.

CAPCOM is optional. Enter your own Anthropic API key in the flight panel to get coaching. The key stays in this tab's memory and goes directly to Anthropic; your API account pays for the calls. Reloading or Disconnect clears it. Use a dedicated key with a provider spending limit.

Docking and scoring

Position: x is distance in front of the docking port, y is sideways, z is vertical. Units are meters, meters/second, and degrees. Dock at range below 0.2 m, roll/pitch/yaw within 0.2°, and each speed component at or below 0.24 m/s. Gravity stays enabled for scored flights. Fine controls are recommended for the final approach.

Only successful flights appear on each track's leaderboard. Lowest simulation time wins, then fewer pulses. Manual standings can filter solo/CAPCOM. Keep the simulator tab visible—browsers throttle hidden pages.

Results are browser-reported with consistency checks and staff review. The event is a hackathon challenge, not a tamper-proof competition platform.
